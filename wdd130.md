# WDD 130 - Web Design and Development

## Project Overview
This is a personal homepage project for WDD 130 (Web Design and Development) course. The project demonstrates HTML and CSS fundamentals through a responsive personal website.

## Contents
- **index.html** - Main page with personal information and navigation
- **styles/** - CSS stylesheets for layout and design
- **images/** - Image assets for the site

## Features
- Responsive web design
- Professional layout with header, navigation, main content, and footer
- CSS styling for typography and spacing
- Image gallery support
